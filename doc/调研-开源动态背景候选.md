## 结论

用户于 2026-08-13 选定第 3 个方案 React Bits Aurora。项目通过 shadcn registry 引入源码并补齐静态降级、离屏/后台暂停、DPR/帧率限制与清理；实施决策见 ADR-026。

## 进入基线的必要条件

1. 只用于登录/欢迎/少量空状态，不覆盖 Dashboard、流水表格和两类日历。
2. Canvas 必须 `aria-hidden`、`pointer-events: none`，真实内容位于独立不透明或半透明表面上并通过 WCAG 2.2 AA。
3. `prefers-reduced-motion` 渲染静态帧或静态 CSS；页面不可见和离开视口时暂停 RAF。
4. 设置设备像素比/分辨率上限和帧率上限；在目标 Web 视口与低端设备档验证帧耗时、GPU 占用和输入响应。
5. 背景初始化失败、WebGL context lost 或脚本未加载时，仍显示完整静态背景和全部功能。
