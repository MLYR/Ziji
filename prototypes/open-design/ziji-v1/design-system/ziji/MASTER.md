# 资迹 Ziji 设计系统

> 所有 Web 与 Mobile 页面优先遵循本文件。页面级覆盖仅在 `pages/` 中存在同名文件时生效。

**项目类型：** 个人与家庭财务管理产品
**设计参数：** 变化度 5/10，动效 4/10，信息密度 9/10

## 字体

- 标题：HarmonyOS Sans SC、PingFang SC、Noto Sans SC
- 正文：PingFang SC、HarmonyOS Sans SC、Noto Sans SC
- 数字：Geist Mono、SFMono-Regular、Consolas
- 金额、日期、百分比和账户编号始终使用等宽数字。

## 尺寸与密度

- 间距以 4px 为基础，主要级别为 8、12、16、24、32px。
- 控件圆角 8px，容器圆角 10-12px，不使用超大药丸卡片。
- Web 触控与键盘控件最小高度 40px，Mobile 最小触控区域 44px。
- Web 主结构使用 224px 固定侧栏和 68px 顶栏，内容最大宽度约 1510px。
- Mobile 以 390px 为设计基准，底部导航固定为 5 项并预留安全区。

## 组件原则

1. 每屏只有一个橙色主要操作；洋红仅用于链接或少量图表序列。
2. 数据密集区域优先使用分隔线、表格与空白，不把所有信息装进同尺寸卡片。
3. 表单标签位于输入框上方，错误紧邻字段，提交提供加载、成功和失败反馈。
4. Dialog 居中，Web 详情使用右侧 Drawer，Mobile 复杂操作使用 Bottom Sheet 或全屏页。
5. 图表必须包含图例、单位、交互提示和可访问文字摘要，不能只提供空轮廓。

## 状态与可访问性

- 正常、悬停、聚焦、按下、禁用、加载、空、错误、无权限、离线、过期和部分可用状态均使用语义令牌。
- 正文对比度至少 4.5:1，大字和图标至少 3:1；颜色不是唯一的信息载体。
- 所有可聚焦元素显示 `:focus-visible` 焦点环，图标按钮具有中文无障碍标签。
- 微交互时长 150-300ms，只动画变换和透明度，并尊重 `prefers-reduced-motion`。
- 流水修改与作废保留审计历史，危险操作必须解释结果与恢复路径。

## 禁止模式

- 不使用大面积蓝紫渐变、霓虹发光、过量玻璃拟态、3D 金币或银行卡插画。
- 不使用 Emoji 作为功能图标，不引入 V1 范围外的预算、目标或自动同步入口。
- 不向用户展示 Debit、Credit、借贷分录或会计科目。
- 不依赖悬停完成关键动作，不允许固定导航遮挡可滚动内容。
