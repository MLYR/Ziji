# 资迹 Ziji 品牌规范

资迹采用精密、可信的黑紫数据界面，橙色只承担主操作与核心焦点，洋红和珊瑚红分别用于少量图表强调与风险反馈。

## 核心 OKLch 令牌

```css
:root {
  --bg: oklch(0.1696 0.0187 289.34);
  --surface: oklch(0.2018 0.0198 289.07);
  --fg: oklch(0.9997 0.0013 106.42);
  --muted: oklch(0.7400 0.0302 281.31);
  --border: oklch(0.3107 0.0269 281.72);
  --accent: oklch(0.7459 0.1800 56.64);
}
```

## 主题映射

- 深色：背景 `oklch(0.1696 0.0187 289.34)`，一级表面 `oklch(0.2018 0.0198 289.07)`，二级表面 `oklch(0.2338 0.0249 287.83)`，悬浮表面 `oklch(0.2631 0.0241 288.14)`。
- 浅色：背景 `oklch(0.9997 0.0013 106.42)`，一级表面 `oklch(0.9770 0.0040 286.33)`，二级表面 `oklch(0.9536 0.0067 286.27)`，边框 `oklch(0.9007 0.0109 291.93)`。
- 语义色：主操作 `oklch(0.7459 0.1800 56.64)`，破坏性 `oklch(0.6721 0.1846 30.02)`，图表辅助 `oklch(0.6131 0.2161 6.04)`；深色主题洋红文字使用 `oklch(0.6300 0.2161 6.04)` 以满足普通文本对比度。

## 视觉语言

1. 使用 1px 冷灰紫边框、8-12px 圆角与局部表面建立层级，不给每个模块加阴影或卡片外壳。
2. 数字统一使用等宽数字；金额、比例、日期和更新时间可在一眼内扫描。
3. 橙色每屏只承担一个主要操作和一个核心数据焦点，洋红只进入少量图表或链接。
4. 所有风险、盈亏、同步状态同时提供文字或图标，不依赖颜色单独传达。
5. 动效只表达状态变化与空间关系，时长 150-300ms，并尊重减少动态效果设置。
