# 总资产日历专项提示词

先完整遵守 `ziji-v1-base.md`，延续已确认的资迹视觉基线，不复制支付宝品牌。

设计 Web 1440px 和 Mobile 390px 的“总资产日历”，各自提供深色与浅色主题。标题固定为“总资产日历”，不得命名为投资收益日历。必须支持“总资产 / 净资产”和“变化金额 / 变化率”切换，展示相邻自然日变化及其归因；内部转账贡献固定为 0。

月历单元格必须使用文字、图标或形态共同区分：完整变化、真实零变化、无资产 `NO_ASSETS`、待数据 `PENDING_DATA`、部分完整 `PARTIAL`、不可用 `UNAVAILABLE`。不要用 0 元或空白代替缺失估值、待处理数据或不可用状态。

点击日期后展示：期初值、期末值、当日变化，以及收入、支出、投资市值变化、负债变化、汇率影响、手工调整和未归因项；同时显示数据截至时间与完整性说明。归因合计必须能解释总变化，无法解释时明确显示未归因差额。

Web 日期详情使用右侧 Sheet；Mobile 使用 Bottom Sheet/Drawer。支持月份切换、回到本月、键盘网格导航、可见焦点、读屏可理解的日期/金额/状态名称，以及空月和估值不完整的修复入口。输出状态画廊，逐一展示全部日期状态。
