# 资迹 Ziji V0.1 原型共用提示词

你正在为“资迹 Ziji”个人与家庭财务管理产品设计高保真、可点击的 Web 与 Mobile 原型。开始前以项目 PRD、UI/UX 设计基线和现有 OpenDesign 原型为事实源；如果业务含义冲突，停止猜测并列出冲突。

视觉方向：以黑色/近黑色为深色主背景，同时提供信息等价的浅色主题；科技感、简约、克制、未来感。组件语言参考 shadcn/ui 与 Radix 的清晰层级和可访问状态，色彩参考 Happy Hues Palette 13 的橙色、洋红与中性色关系，但不得复制第三方品牌或页面。中文界面，金额和日期使用等宽数字。

输出 Web 1440px 与 Mobile 390px。保持 4px 间距网格、Web 控件至少 40px、Mobile 触控区至少 44px；不允许 Mobile 页面整体横向滚动。所有关键页面覆盖默认、加载、空、错误、无权限、离线、同步、冲突、部分数据和过期状态，并提供恢复动作。关键金额、盈亏、风险和数据质量不能只靠颜色表达。

演示数据必须明确为演示数据。不得增加预算、财务目标、微信/手机号登录、银行自动同步、实物资产或盘中实时行情入口。不得用 0 代替待数据、缺失估值或未加载。原型只冻结信息架构、视觉与交互，不得发明账务、权限或 API 规则。

生成物应为可独立打开、可点击的 HTML/CSS/JS 原型和必要资源，提交到指定候选目录；不要输出外部工具 skill、插件、缓存或会话文件。必须附页面索引、关键交互说明和状态覆盖清单，等待产品评审，不得声称已成为生产实现基线。
