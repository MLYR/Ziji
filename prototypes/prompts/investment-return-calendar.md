# 投资收益日历专项提示词

先完整遵守 `ziji-v1-base.md`，延续已确认的资迹视觉基线，不复制支付宝品牌。

设计 Web 1440px 和 Mobile 390px 的“投资收益日历”，各自提供深色与浅色主题。必须支持“全部投资 / 单一标的”范围切换，以及“收益金额 / Modified Dietz 收益率”指标切换。收益率分母无效时显示“收益率不可用”，绝不能显示 0%。

月历单元格必须使用文字、图标或形态共同区分：正收益、负收益、真实零收益、非交易日 `NON_TRADING_DAY`、无持仓 `NO_POSITION`、待数据 `PENDING_DATA`、部分完整 `PARTIAL`、缺估值 `UNPRICED`。不要把这些状态合并成空白或 0。

点击日期后：

- 全部投资视图展示标的、券商现金和未归因项的贡献，贡献合计必须等于组合日收益。
- 单一标的视图展示日初/日终市值、净现金流、价格、汇率、分红、手续费和税费影响。
- 转入转出和买卖本金不得显示为收益。

Web 日期详情使用右侧 Sheet；Mobile 使用 Bottom Sheet/Drawer。支持月份切换、回到本月、键盘网格导航、可见焦点、读屏可理解的日期/收益/状态名称，以及空月和数据异常的恢复入口。输出状态画廊，逐一展示全部日期状态。
